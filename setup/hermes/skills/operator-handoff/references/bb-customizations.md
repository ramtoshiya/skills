# BB customizations {:#bb-customizations}

For BB customizations, use supported BB settings or plugins. Before proposing
an approach or creating a brief, do not propose, draft, or use a BB application
fork, a personal core patch, or an installed bundle patch unless the user
explicitly requests that route. Approval of a desired behavior alone does not
authorize it. The generic third-party fork authority in Write the brief in
`SKILL.md` does not grant authority to use a BB application fork. You may
investigate the core and SDK boundary read-only. If supported settings or
plugins cannot deliver the behavior, state the limit and surface the upstream
request or bug report route without starting fork-backed work.
